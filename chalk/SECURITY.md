# Security policy

Please use GitHub's private reporting flow for anything that may affect the confidentiality, integrity, or availability of Chalk or a datapack it builds. Open a [private vulnerability report](https://github.com/iamkaf/chalk/security/advisories/new) with the affected version, impact, reproduction steps, and any suggested mitigation. Do not open a public issue for a suspected vulnerability.

Use [GitHub Issues](https://github.com/iamkaf/chalk/issues) for reproducible non-security bugs, support, setup questions, and ideas.

Security fixes target the latest release. If a report affects older releases too, include that information so the advisory can describe the complete affected range.
